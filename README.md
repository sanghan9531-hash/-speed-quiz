# 🎤 스피드 퀴즈 쇼

교실이나 친구들과 함께하는 **스피드 퀴즈 게임**입니다. 설치 없이 브라우저에서 바로 실행돼요.

## 게임 방법

1. 로비에서 주제를 고릅니다: **동물 · 캐릭터 · 음식 · 나라 · 직업 · 운동** (주제별 단어 60개)
2. 3초 카운트다운 후 게임이 시작됩니다. 제한시간은 **2분**입니다.
3. 한 명이 화면의 단어를 설명하고, 다른 사람들이 맞힙니다.
4. 버튼으로 결과를 기록합니다.

| 버튼 | 키보드 | 설명 |
|------|--------|------|
| 정답 | `Enter` | 맞힘, 다음 단어 |
| 오답 | `X` | 틀림, 다음 단어 |
| 패스 | `Space` | 넘기기 |

게임이 끝나면 맞힌 개수와 푼 단어 목록이 나옵니다.

- 난이도: 초등학교 고학년 ~ 중학교 1·2학년
- 단어는 랜덤 순서로 나오고, 한 판 안에서는 겹치지 않습니다.

## 🥚 이스터에그

로비 맨 위의 `???` 입력창 어딘가에 **숨겨진 모드 3개**가 있습니다. 찾아보세요!

## 실행 방법

- `index.html`을 내려받아 브라우저로 열면 됩니다.
- 또는 GitHub Pages로 배포해서 링크로 공유할 수 있습니다.

## 기술

HTML · CSS · JavaScript 한 파일로 만들었습니다. 라이브러리는 사용하지 않았고, 폰트는 Google Fonts(Black Han Sans, Jua, Gowun Dodum)를 사용합니다. 라이트/다크 모드를 모두 지원합니다.
